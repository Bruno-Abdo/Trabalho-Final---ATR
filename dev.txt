3. Módulos principais (escopo e limites)
Use estes módulos como “espinha dorsal”:
3.1. model/truck_state.py
   * Definir uma classe (p.ex. TruckState, usando dataclass) com, no mínimo:
      * Sensores:

         * i_posicao_x, i_posicao_y, i_angulo_x
         * i_temperatura
         * i_falha_eletrica, i_falha_hidraulica

            * Atuadores:

               * o_aceleracao, o_direcao

                  * Opcional (somente se eu pedir): estados da Tabela 2 (e_defeito, e_automatico, etc.).

                  * Não adicione atributos “inventados” sem justificar com base no documento ou em necessidade direta da simulação.

3.2. model/dynamics.py
     * Implementar funções simples de equações de diferenças para a dinâmica:

        * update_position(state, dt)
        * update_angle(state, dt)
        * update_temperature(state, dt)

           * Comece com um modelo simples e estável (por exemplo, MRUV 2D) e só complique se eu pedir.

3.3. model/faults.py
  * Funções para injetar falhas:

     * set_electrical_fault(state, enabled: bool)
     * set_hydraulic_fault(state, enabled: bool)
     * eventual função para “temperatura crítica”.

        * Esses métodos serão acionados pela UI (botões/checkboxes).
3.4. core/random_sources.py
    * Funções para ruído de média nula, por exemplo:

       * gaussian_noise(mean=0.0, std: float)
       * apply_noise(value, noise_config)

          * Não crie um framework de probabilidade completo; foque no mínimo necessário para:

             * posição,
             * ângulo,
             * temperatura.

3.5. core/simulator.py
    * Classe Simulator responsável por:
    * Manter um TruckState interno;
    * Avançar o tempo com dt controlado (via QTimer ou thread);
    * Aplicar dinâmica (dynamics.py) e ruído (random_sources.py);
    * Respeitar:

       * faixa de valores (mín/máx) e
       * taxa de atualização configurada para cada variável ou grupo de variáveis;
       * Emitir algum tipo de notificação (callback ou Qt signal) com o TruckState atualizado.

          * Deve ter uma API simples, como:

             * start(), stop()
             * set_update_config(variable_name, config).

3.6. core/publisher.py
    * Cliente MQTT (p.ex. paho-mqtt) com interface mínima:
    * connect()
    * publish_state(truck_id, state: TruckState)

       * Publicar em tópicos do tipo:
       * atr/mine/truck/<id>/sensors
       * Não implemente subscribers aqui, a menos que eu peça.
